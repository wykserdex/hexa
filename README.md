# HEXA — обвязка для Dota 2

> **Добавлен экспериментальный [HEXA Lab](HEXA-LAB.md):** рабочий симулятор с комбо, автопредметом, фармом, микроконтролем, приоритетами и веб-интерфейсом. Запуск: `python -m hexa lab` → http://127.0.0.1:8080. **Это не интеграция с обычными матчами Dota.** Исходный режим ниже оставлен отдельно.

Своё DLC: ставится рядом с клиентом, открывается по клавише, включает модули тумблерами.
Ядро и модули лежат открыто (опенсорс), живой канал данных — официальный GSI от Valve.

## Четыре пункта, как они реализованы

| Пункт | Где в коде | Что даёт |
|---|---|---|
| **1. Обвязка как у Амбреллы** | `registry.py`, `config.py`, `hotkeys.py`, `menu.py` | меню по `INSERT`, тумблеры модулей, конфиги в JSON, хоткеи, hot reload |
| **2. Модули, меняющие клиент** | `bridges/panorama.py` | патч интерфейса в стиле Minify: `styling.css` (акцент, миникарта, хад), `hud.js` (панель таймеров для кастомки) |
| **3. Автоматизация в песочнице** | `modules/sandbox_combo.py`, `bridges/sandbox.py` | комбо уходит в sink действий; вне песочницы модуль прямо говорит, почему не может |
| **4. Продукт как подписка** | `config.py`, `menu.py` | конфиги переносимы (облако, конфиг-паки), меню — витрина: модулей может быть 4 или 40 |

## Носитель: как обвязка получает руки в игре

Python-сторона считает, игра исполняет. Цикл замкнут через официальные интерфейсы:

```
HEXA (Python)  ──GET /state──▶  Panorama HUD  ──CustomGameEvent──▶  серверный Lua  ──▶  игра
       ▲                             │
       └──────POST /event────────────┘   (хоткеи, игровое время)
```

```bash
python -m hexa --sandbox serve     # GSI :3000 + мост действий :3001 — одной командой
curl http://127.0.0.1:3001/state   # то, что видит HUD кастомки
```

Проверено реальными запросами: `/state` отдаёт таймеры, уведомления, отметки и очередь
действий; `POST /event` типа `hotkey` запускает комбо (`seq1..seq4` в очереди); GSI-пейлоад
с `:3000` порождает те же уведомления. Готовые файлы для игры — в `carrier/`:
серверный Lua кастомки, разметка HUD, бот-мост с чат-командами.

## Установка (2 минуты)

```bash
pip install -r requirements.txt          # зависимостей нет, только stdlib
python -m hexa gsi --write-cfg ~/hexa/gamestate_integration_hexa.cfg
```

1. Файл из прошлого шага положить в
   `<Steam>/steamapps/common/dota 2 beta/game/dota/cfg/gamestate_integration/`
2. Добавить Доте параметр запуска `-gamestateintegration`
3. Запустить `python -m hexa gsi` — приёмник встанет на `127.0.0.1:3000`
4. Для визуала: `python -m hexa build-panorama --out build/panorama` и применить `styling.css`
   через [Minify](https://github.com/robbyz512/dota2-minify) как `styling.txt`

## Границы (и почему они такие)

- **Живые данные — только GSI.** Valve в матче отдаёт исключительно твоего героя. Никаких
  панелей с врагами, кулдаунами чужой команды и прочей скрытой информации в проекте нет и не будет:
  это не «мы так решили», это свойство канала.
- **Автоматизация — только песочница.** Комбо и прочие автодействия исполняются там, где нет живых
  людей: боты, своё лобби, кастомка. В обычном режиме sink — трейс, физически не влияющий на игру.
- **Клиентские моды — только косметика.** CSS/VPK-патчи в стиле Minify: цвета, размеры, расположение.
  Всё, что показывает скрытое, — за чертой.
- **Макросов, повторяющих твой ввод, нет.** Ни инжекта, ни чтения памяти, ни эмуляции кнопок.

## Файлы

```
hexa/config.py            конфиг, тумблеры, секции модулей
hexa/hotkeys.py           действия и биндинги, проверка конфликтов
hexa/timers.py            расписания рун/стаков, ручные отметки
hexa/module.py            контракт модуля (видит только GSI и часы)
hexa/runtime.py           контекст: уведомления, хоткеи, sink действий
hexa/registry.py          загрузка модулей, изоляция падений, тумблеры
hexa/menu.py              модель меню → TUI, HTML, Panorama
hexa/bridges/gsi.py       приёмник GSI + генератор gamestate-конфига
hexa/bridges/http_bridge.py  мост в игру: /state для HUD, /event от HUD, очередь действий
hexa/bridges/panorama.py  патч интерфейса (styling.css / hexa_hud.js / blacklist)
hexa/bridges/sandbox.py   sink действий: трейс по умолчанию, GuardedSink с проверкой песочницы
carrier/                  носитель: Lua кастомки, разметка HUD, бот-мост (см. carrier/README.md)
hexa/modules/             4 модуля
hexa/cli.py               modules | hotkeys | demo | serve | gsi | build-panorama | preview
```
